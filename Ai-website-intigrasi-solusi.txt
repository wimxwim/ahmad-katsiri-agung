🔴 MASALAH 1 — NaraRouter 502 Bad Gateway (PALING SERING)
Bukti
- File: src/lib/ai.ts baris 63-76
- Error message: NaraRouter error 502: <!DOCTYPE html> <!--[if lt IE 7]> <html class="no-js ie6 oldie"...
- Frekuensi: 6 dari 12 draft gagal dengan error ini
- Health check: GET /v1/models → ✅ 200 OK (connected, 633ms)
- Uji lokal: POST /v1/chat/completions dari laptop → ✅ 200 OK (payload kecil & besar)
- Uji dari Vercel: POST /v1/chat/completions → ❌ 502 dengan HTML Cloudflare
Root Cause
NaraRouter mengembalikan 502 dari Cloudflare—artinya origin server NaraRouter (atau upstream AI provider) gagal merespons. Ini bukan bug di kode AKAL Center, tapi masalah di sisi NaraRouter.
Namun, ada faktor yang memperparah:
1. Tidak ada retry logic. chat() di ai.ts baris 63 hanya melakukan satu kali fetch() dengan AbortSignal.timeout(60_000). Jika NaraRouter sedang intermittent, tidak ada percobaan ulang.
// ai.ts:63 — TIDAK ADA RETRY
const res = await fetch(url, {
  method: "POST",
  headers: { ... },
  body: JSON.stringify(body),
  signal: AbortSignal.timeout(60_000),
});
2. Tiga panggilan chat() paralel sekaligus (ai-generator.ts:143-169). Tiga request besar ke model berat (deepseek-v4-pro) dikirim bersamaan. Ini bisa memicu rate limiting di NaraRouter.
3. Tidak ada fallback model. Jika deepseek-v4-pro gagal, tidak ada fallback ke deepseek-v4-flash (yang lebih murah dan lebih ringan).
Rekomendasi Fix
A. Tambahkan retry logic ke chat():
// src/lib/ai.ts — tambahkan retry
export async function chat(
  messages: ChatMessage[],
  options: ChatOptions = {},
  retries = 2,
): Promise<ChatResult> {
  for (let attempt = 0; attempt <= retries; attempt++) {
    try {
      // ... fetch logic yang sama ...
      if (!res.ok) {
        const text = await res.text().catch(() => "");
        // 502/503/504 = retryable, 401/403/429 = jangan retry
        if ([502, 503, 504].includes(res.status) && attempt < retries) {
          await new Promise(r => setTimeout(r, 1000 * Math.pow(2, attempt)));
          continue;
        }
        throw new Error(`NaraRouter error ${res.status}: ${text.slice(0, 300)}`);
      }
      // ... parse response ...
    } catch (e) {
      if (attempt < retries && e instanceof TypeError) {
        // Network error → retry
        await new Promise(r => setTimeout(r, 1000 * Math.pow(2, attempt)));
        continue;
      }
      throw e;
    }
  }
  throw new Error("NaraRouter failed after all retries");
}
B. Tambahkan fallback model untuk heavy task:
// ai-generator.ts — fallback jika heavy model gagal
async function chatWithFallback(
  messages: ChatMessage[],
  options: ChatOptions,
): Promise<ChatResult> {
  try {
    return await chat(messages, options);
  } catch (e) {
    // Jika heavy model gagal, coba flash model
    if (options.model === getModelForTask("heavy")) {
      console.warn("Heavy model failed, falling back to flash:", e);
      return await chat(messages, { ...options, model: getFlashModel() });
    }
    throw e;
  }
}
C. Kurangi request paralel—jangan 3 sekaligus:
// ai-generator.ts — sequential instead of Promise.all
const materiRes = await chatWithFallback([...], { model: getModelForTask("heavy"), ... });
const quizRes = await chatWithFallback([...], { model: getModelForTask("light"), ... });
const soalRes = await chatWithFallback([...], { model: getModelForTask("heavy"), ... });
🔴 MASALAH 2 — DOMMatrix is not defined (PDF Extraction)
Bukti

Root Cause

  MAX_EXTRACT_TIME_MS, "membuka PDF",
);
Rekomendasi Fix
Opsi A — Install polyfill canvas (recommended):
npm install canvas
pdfjs-dist secara otomatis mendeteksi canvas dan akan menggunakannya sebagai pengganti DOM API. Ini adalah solusi standar untuk pdfjs-dist di Node.js.
Opsi B — Update unpdf ke versi terbaru:
npm install unpdf@latest
Versi terbaru unpdf mungkin sudah memperbaiki ini.
Opsi C — Fallback ke pdf-parse untuk production:
Jika canvas tidak bisa di-install (butuh native dependencies), gunakan pdf-parse sebagai fallback. pdf-parse tidak membutuhkan DOM API.

- Kalau AI output tidak valid, berarti model menjawab tapi format JSON gagal.
- Kalau DOMMatrix, berarti extraction masih kena bug runtime.
- Kalau Generation timeout at stage: ai-materi/ai-quiz/ai-soal, berarti timeout per tahap masih kurang atau model lambat.
Rencana Fix Yang Benar
Karena plan mode aktif, saya belum mengubah apa pun. Rencana eksekusi yang paling aman:
1. Pastikan fix yang sudah ada benar-benar sudah deploy ke production.
2. Jalankan curl -X POST https://akalcenter.my.id/api/readyz untuk isolate NaraRouter dari Vercel.
3. Jalankan upload PDF baru dan pantau draft.
4. Kalau 502 masih muncul, tambahkan logging status per attempt: model, status code, latency, stage.
5. Kalau 502 hanya pada deepseek-v4-pro, ubah heavy default sementara ke deepseek-v4-flash.
6. Kalau 502 masih pada semua model dari Vercel, pindah AI call ke provider alternatif atau jalankan worker di environment lain.
7. Kalau DOMMatrix muncul lagi pada upload baru, fallback dari unpdf ke extractor lain atau force clean Vercel build cache.
Catatan Keamanan Penting
Di log sebelumnya ada API key NaraRouter yang sempat terlihat dalam chat/terminal. Karena repo public dan insiden credential pernah terjadi di project ini, key itu sebaiknya dianggap bocor dan dirotasi setelah debugging selesai. Jangan pakai key yang sudah pernah tampil plaintext.
Jawaban Jujur
- DOMMatrix: bisa difix, dan dependency sekarang sudah di versi yang seharusnya membawa fix.
- Timeout: bisa difix, dan kode lokal sekarang sudah naik ke 120 detik.
- 3 request paralel: bisa difix, dan kode lokal sekarang sudah sequential.
- NaraRouter 502: bisa dikurangi drastis, tapi kalau sumbernya NaraRouter/upstream/IP Vercel, tidak bisa dijamin dari kode saja. Perlu fallback provider/model atau pindah eksekusi AI dari Vercel jika hasil test /api/readyz POST tetap 502.

### 18.6 Production Stability Contract — AI Document Pipeline

Per 11 Juli 2026, alur upload dokumen sudah berhasil di production setelah masalah berlapis: build Vercel gagal karena import ikon yang tidak tersedia, health check AI membaca env salah, NaraRouter `GET /v1/models` hidup tetapi `POST /v1/chat/completions` dari Vercel timeout, dan output soal AI kadang meleset dari schema.

Kontrak ini **jangan diubah tanpa bukti production baru**:

1. `src/lib/ai.ts` memakai endpoint OpenAI-compatible NaraRouter dengan fallback base URL:

   ```txt
   https://router.bynara.id/v1
   ```

   Key dibaca dari `AI_API_KEY || NARAROUTER_API_KEY`. Jangan wajibkan `AI_BASE_URL` karena env itu boleh kosong.

2. `src/lib/ai-generator.ts` harus mempertahankan local fallback generator. Jika NaraRouter timeout/502/504 dari Vercel, sistem tetap membuat draft materi, quiz, dan soal dari teks ekstraksi agar guru tidak melihat upload gagal total.

3. `src/lib/ai-sanitizer.ts` harus mempertahankan normalisasi output AI. Variasi seperti `Pilihan Ganda`, `items`, `questions`, `choices`, opsi array, atau kunci berupa teks jawaban harus dinormalisasi dulu sebelum Zod schema final.

4. Draft tidak boleh gagal total hanya karena bagian soal invalid. Minimal materi dan quiz yang valid tetap disimpan sebagai draft. Semua hasil tetap draft dan wajib direview guru.

5. Health check `/api/health` harus menampilkan kondisi realistis: ImageKit connected, AI connected untuk `GET /models`, Supabase REST `not_applicable` jika app tetap memakai Drizzle/Postgres langsung.

6. Jangan impor `@animateicons/react/lucide` di production. Dashboard guru harus memakai `lucide-react` karena package path itu pernah membuat Vercel build gagal.

### 18.7 Upgrade Path yang Aman

Upgrade yang disarankan bukan menghapus fallback, tetapi mengganti lapisan reliability dengan pengganti yang terbukti:

1. **Durable AI job queue** — upload route cukup menyimpan file dan enqueue job. Worker/queue yang memproses ekstraksi dan AI. Pilihan: Vercel Workflows, Cloudflare Queue/Worker, atau VPS worker.

2. **Vercel AI Gateway** — gunakan base URL OpenAI-compatible `https://ai-gateway.vercel.sh/v1` dengan `AI_GATEWAY_API_KEY` atau BYOK. Ini memberi observability, model routing, dan lebih cocok dengan runtime Vercel.

3. **NaraRouter support escalation** — laporkan bahwa `GET /v1/models` dari Vercel berhasil tetapi `POST /v1/chat/completions` timeout 504. Sertakan timestamp, region Vercel, dan model yang dipakai. Jangan kirim API key.

4. **Quality fallback upgrade** — fallback lokal sekarang adalah safety net agar fitur tidak mati. Jika kualitas ingin ditingkatkan, buat template deterministic yang lebih pedagogis atau jadikan fallback sebagai draft minimal yang bisa diregenerate ketika provider AI sehat.

Iya.
Fallback lokal hanya aktif kalau request AI gagal/timeout.
Jadi kalau model NaraRouter berhasil:
draft dari AI asli
Kalau model gagal:
draft fallback lokal
Itulah kenapa sistem sekarang tidak mati total.
Cara cek model mana yang dipakai
Bisa cek dari draft:
modelName
Atau dari env Vercel:
npx vercel env ls | grep AI_MODEL
Tapi nilai env encrypted, tidak terlihat plaintext.
Jawaban paling singkat
- Bisa diganti.
- AI sekarang bukan AI gratis Vercel.
- AI sekarang pakai API key NaraRouter kamu.
- Vercel hanya menjalankan server website.
- Model dikontrol lewat env:
AI_MODEL
AI_FLASH_MODEL
- Untuk stabilitas, saya sarankan pakai model cepat dulu, misalnya:
AI_MODEL=mimo-v2.5
AI_FLASH_MODEL=mimo-v2.5
atau:
AI_MODEL=deepseek-v4-flash
AI_FLASH_MODEL=deepseek-v4-flash
Fallback lokal tetap wajib dipertahankan supaya upload tidak gagal lagi.
